# حالة المشروع

## مؤكد ومعتمد

- الكتاب الأول: آدم عليه السلام.
- النص الافتتاحي «حين بدأ الإنسان» معتمد.
- رحلة آدم: ثماني مراحل تكوينية.
- صورة افتتاحية مستقلة لكل مرحلة، مبنية على معناها.
- صور المراحل بلا نص تقريبًا؛ فقط رقم المرحلة وعنوانها.
- إنفوجرافيك ختامي لكل رحلة نبي يلخص ويبني الفكر والسلوك.
- حد اعتماد الصورة: 98/100.
- التقييم النظري يسبق الإنشاء، ثم تقييم الناتج.
- كل خطأ يتحول إلى قاعدة تميز للمحاولة التالية.

## قيد الاستعادة

- الأسماء النهائية الكاملة للمراحل الثماني.
- النصوص النهائية لكل مرحلة.
- الصور المعتمدة نهائيًا من المحادثات السابقة.
- مواصفات الإنفوجرافيك النهائية.
- سجلات QCE التفصيلية المرتبطة بآدم.

## ممنوع

- اختراع محتوى مفقود.
- اعتبار مرجع تاريخي صورة معتمدة.
- خلط المعتمد بالمحاولات أو بالمستبدل.
