# القواعد البصرية المعتمدة

1. صورة افتتاحية واحدة لكل مرحلة.
2. تجسد معنى المرحلة لا مجرد حدث سطحي.
3. لا نص إلا رقم المرحلة وعنوانها تقريبًا.
4. الإنفوجرافيك الختامي استثناء.
5. لا إنشاء قبل الجاهزية النظرية.
6. لا اعتماد نهائي تحت 98/100.
7. كل ملاحظة تتحول إلى قاعدة تميز.
8. الصور القديمة مصادر تعلم وليست معتمدة تلقائيًا.
