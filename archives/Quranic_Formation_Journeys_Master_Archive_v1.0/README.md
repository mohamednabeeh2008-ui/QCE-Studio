# رحلات التكوين القرآنية — Master Archive v1.0

الإصدار التأسيسي الرسمي للأرشيف.

- الحالة: استعادة منظمة قيد التنفيذ.
- القاعدة: لا يُوسم عنصر بأنه «معتمد» إلا إذا ثبت اعتماده.
- لا يدّعي هذا الإصدار احتواء كل تاريخ المشروع؛ بل يؤسس نقطة استعادة محاسبية تمنع خلط المعتمد بالمفقود أو المستبدل.

## المحتوى

- حالة المشروع.
- سجل القرارات المعتمدة.
- النص الافتتاحي المعتمد لرحلة آدم.
- القواعد البصرية الأساسية.
- جرد الاستعادة.

## قاعدة الأمانة

لا يُخترع أي محتوى مفقود، ولا تُعتبر المراجع التاريخية مواد معتمدة تلقائيًا.
