# PASS-J11 — Cross-Event Journey Resolution

Status: LOCKED
Version: 1.0

## Purpose
Determine when one formation journey may legitimately span multiple Event Families without confusing chronology, thematic similarity, or character continuity with formation continuity.

## Core rule

`CROSS-EVENT CONTINUITY MUST BE PROVEN; IT IS NEVER INHERITED FROM CHRONOLOGY.`

## Admission gates

A cross-event journey requires all of the following:

1. Same resolved formation subject.
2. Stable formation problem across the candidate span.
3. Each later event changes, tests, deepens, or closes the same transition identity.
4. Removing an intermediate event materially damages the explanatory chain.
5. No event contains a sufficient independent T0 → T1 identity that should remain separate.
6. Chronology alone is insufficient.
7. Shared theme alone is insufficient.
8. Character fame alone is insufficient.

## Relation outcomes

```text
MERGE_AS_ONE_JOURNEY
LINK_AS_PROGRESSION
LINK_AS_CONTRAST
LINK_AS_ECHO
KEEP_INDEPENDENT
HOLD
```

## Retrospective tests

### Ibrahim: father/separation → confrontation/departure → house/generations

Result: `LINK_AS_PROGRESSION`, not one journey.

Reason: the three Event Families contain distinct challenges and independently intelligible transition identities. The wider sequence may form a character-level progression, but it does not erase event-level journeys.

### Noah: mission persistence → construction

Result: `KEEP_WITHIN_ONE_LONG-MISSION TRANSITION ONLY WHERE RESPONSE-HORIZON CLOSURE IS THE REQUIRED BRIDGE`.

The invitation and construction phases are not merged because they are chronologically adjacent. They remain one promoted journey only at the precise mission-mode transition already locked in J-000002.

### Adam recovery arc and Noah son arc

Result: `LINK_AS_ECHO`, never merge.

Shared capacity resonance does not create cross-event identity across different subjects and Event Families.

## Cross-event identity test

```text
SAME SUBJECT
+
SAME FORMATION PROBLEM
+
DEPENDENT TRANSITION CHAIN
+
NO INDEPENDENT IDENTITY COLLAPSE
=
CROSS-EVENT JOURNEY ELIGIBLE
```

## Result

```text
CANDIDATE CHAINS TESTED: 3
```

## Lock decision

`EVENT FAMILIES MAY BE LINKED FREELY AS HYPOTHESES, BUT MAY BE MERGED INTO ONE JOURNEY ONLY BY TRANSITION DEPENDENCY.`

PASS-J11: PASS / LOCKED
