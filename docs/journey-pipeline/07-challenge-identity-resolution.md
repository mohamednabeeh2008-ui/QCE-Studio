# PASS-J07 — Challenge Identity Resolution

Status: LOCKED
Version: 1.0

## Purpose
Prevent event, pressure, trial, problem, and formation challenge from being treated as synonyms.

## Core distinction

```text
EVENT = what happens
PRESSURE = what bears on the subject
PROBLEM = what must be resolved
TRIAL = a textually or structurally bounded testing condition
FORMATION CHALLENGE = the specific obstacle whose passage explains the T0 → T1 transition
```

## Resolution algorithm

```text
EVENT INVENTORY
→ SUBJECT LOCK
→ PRESSURE INVENTORY
→ PROBLEM STATEMENT
→ TRANSITION DEPENDENCY TEST
→ CHALLENGE IDENTITY
→ DUPLICATE CHALLENGE TEST
→ LOCK
```

A challenge is canonical only if removing it makes the journey transition unintelligible or materially different.

## Anti-inflation rules

1. One event may contain multiple challenges.
2. One challenge may appear across multiple witnesses.
3. A dramatic event is not automatically the formation challenge.
4. Popular lesson titles cannot define challenge identity.
5. Reader difficulty cannot be imported into the subject's challenge.
6. Challenge counting is blocked until subject and journey boundaries are locked.
