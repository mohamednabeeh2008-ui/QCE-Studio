2. Formation challenge is the transition-dependent obstacle, not the most dramatic event.
3. Journey count follows independent transition identities, not people, events, or speakers.
4. Shared event does not imply shared journey.
5. Subject capacity and reader capacity are separate layers.
6. Re-resolution must reduce ambiguity, not merely increase journey count.
7. Governance recovery is not data recovery.
8. Existing node is not recovered edge.
9. Missing does not mean never existed.
