# QPFS — Quranic Parable Formation System

Status: Active
Architecture phase: 15–24 approved
Next legal campaign: 24.5 → 27

QPFS is the QCE subsystem for discovering, delimiting, profiling, validating, and eventually canonizing Quranic parable units without equating lexical occurrence with parable identity.

## Governing principle

Discovery is not classification. Classification is not motion. Motion is not journey. Journey is not formation. No analytical discovery becomes canonical without evidence and review.

## Non-negotiable rules

1. No predetermined number of Quranic parables.
2. Root occurrence does not equal parable unit.
3. Multi-channel entry does not create duplicate candidates.
4. Link before merge.
5. Ambiguity may remain `UNRESOLVED`.
6. Candidate entry never stores journey, stations, formation subject, or canonical network membership.
7. The canonical QPU corpus remains locked until triage, boundary resolution, and formal parable decisions are complete.
